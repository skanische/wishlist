# Вишлист

Личная страница с идеями подарков: категории, иллюстрации и копирование текста каждого пункта. Статический сайт без внешних сервисов.

## Локальный запуск

Требуется Python 3. Из корня проекта:

```sh
python -m http.server 4173 --bind 127.0.0.1 --directory dist
```

Открыть http://127.0.0.1:4173. Если установлен npm, доступен `npm start`.

Для простого просмотра можно открыть `dist/index.html` напрямую; поведение буфера обмена зависит от браузера.

## Содержание и оформление

Список редактируется в `dist/index.html`, стили — в `dist/style.css`, копирование — в `dist/app.js`. Шрифт Onest хранится локально, его лицензия SIL OFL находится в `dist/fonts/OFL.txt`.

## Проверки

Требуется Node.js:

```sh
node --check dist/app.js
node verify.cjs
```

Либо `npm run verify`. Проверка охватывает структуру списка и логику копирования, включая отказ clipboard. Она не заменяет проверку в браузере и на телефоне.

## Состояние alpha

- Нет бронирования, аккаунтов и редактора; обновление через Git.
- При отказе автоматического копирования открывается поле для ручного копирования.
- При быстром повторном нажатии той же кнопки её подтверждение может сброситься раньше времени; нижнее уведомление продлевается корректно. Исправление отложено.
- Печатное оформление добавлено, но печатный предпросмотр ещё не проверен.
- Проверка на реальном телефоне запланирована после demo.

Для demo подготовлен workflow `.github/workflows/pages.yml`: после включения GitHub Pages через GitHub Actions успешный push в develop публикует только dist. Workflow не выполняет релиз из основной ветки. Код и шрифты — разные объекты лицензирования: лицензия шрифта не задаёт лицензию исходного кода проекта.
