# Вишлист

Меня часто спрашивают, что подарить. Обычно я собираю вишлист осенью, а после праздников он куда-то теряется - и через год приходится начинать заново. Этот проект появился, чтобы у списка было постоянное место.

Идея простая: личная страница, которой можно поделиться по ссылке. В моём списке нет ссылок на конкретные товары, потому что я хочу оставить дарителю свободу выбора и помогаю сделать сюрприз. В то же время этот проект - основа для вашего вишлиста. Интеграции и другие возможности пока оставлены на будущее.

Демо - мой текущий вишлист: [этой ссылкой](https://skanische.github.io/wishlist/) я делюсь с друзьями. Для стабильной версии предназначена ветка `main`, а в `develop` и рабочих ветках я вношу изменения.

На данном этапе список включает категории, иллюстрации и возможность копирования каждого пункта.

## Локальный запуск

Требуется Python 3. Из корня проекта:

```sh
python -m http.server 4173 --bind 127.0.0.1 --directory dist
```

Открыть http://127.0.0.1:4173. Если установлен npm, доступен `npm start`.

Для простого просмотра можно открыть `dist/index.html` напрямую; поведение буфера обмена зависит от браузера.

## Содержание и оформление

Список редактируется в `dist/index.html`, стили — в `dist/style.css`, копирование — в `dist/app.js`. Шрифт Onest хранится локально, его лицензия SIL OFL находится в `dist/fonts/OFL.txt`.

## Проверки

Требуется Node.js:

```sh
node --check dist/app.js
node verify.cjs
```

Либо `npm run verify`. Проверка охватывает структуру списка и логику копирования, включая отказ clipboard. Она не заменяет проверку в браузере и на телефоне.

## Статус проекта

- Хочу добавить бронирование подарков, аккаунты и редактор. Пока список обновляется через Git.
- При отказе автоматического копирования открывается поле для ручного копирования.
- Основные сценарии проверены на компьютере и телефоне.
- Печатный предпросмотр проверен: заголовки остаются рядом с пунктами.

Для публикации используется workflow `.github/workflows/pages.yml`: после успешных проверок push в `main` обновляет сайт из папки `dist`. Изменения в `develop` автоматически не публикуются.
